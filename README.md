E-commerce Sales Data Analysis

Project Overview

This project focuses on analysing an online retail dataset using Python to understand sales performance, product trends, customer purchasing behaviour, and country-wise revenue.

The goal is to extract meaningful business insights through data cleaning, exploratory data analysis (EDA), and data visualisation.

Dataset

- Dataset: Online Retail Dataset
- Source: UCI Machine Learning Repository
- Original records: 541,909
- Number of features: 8
- Data format: Excel (.xlsx)

Tools and Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Data Cleaning

The following data-cleaning operations were performed:

- Checked missing values.
- Identified and removed duplicate records.
- Inspected column names and data types.
- Converted invoice dates into datetime format.
- Created a new Revenue column.
- Excluded cancelled transactions and invalid sales records for sales analysis.

Exploratory Data Analysis (EDA)

The following analyses were performed:

- Total revenue calculation.
- Monthly sales analysis.
- Daily sales analysis.
- Top 10 best-selling products.
- Top 10 revenue-generating products.
- Country-wise revenue analysis.
- Customer spending analysis.
- Average order value calculation.

Data Visualization

Created visualizations using Matplotlib and Pandas:

- Monthly revenue trend.
- Top 10 best-selling products.
- Top 10 countries by revenue.
- Top 10 customers by spending.
- Country-wise revenue contribution.

Key Business Insights

This project helps identify:

- Products with the highest sales quantities.
- Products generating the highest revenue.
- Countries contributing the most to total revenue.
- Customers with the highest spending.
- Monthly and daily sales patterns.
- Average revenue generated per invoice.

Conclusion

This project demonstrates how Python can be used to clean, analyse, and visualise real-world e-commerce transaction data.

The analysis provides useful insights into sales performance, product popularity, and customer purchasing behaviour.

Future Improvements
